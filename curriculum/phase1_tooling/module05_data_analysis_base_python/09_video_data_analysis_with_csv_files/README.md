# 🎬 Video: Data Analysis with CSV Files

> Part of **Topic 3: Data Analysis in Base Python** · source item type: WikiPage

---
In this video Greg Damico talks about using base Python to perform data analysis. Topics covered in this lesson include: the csv Python library, loading a csv file, getting the file path for a file, inspecting a file, printing lines in bash, simple data cleaning, and some additional topics such as the datetime data type.

The repository for this lecture can be found here - [Data Analysis with CSV's](https://github.com/flatiron-school/ds-data_analysis_csv-bqs-32)
