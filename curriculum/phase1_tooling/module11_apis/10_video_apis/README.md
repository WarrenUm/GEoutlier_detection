# 🎬 Video: APIs

> Part of **Topic 9: APIs** · source item type: WikiPage

---
In this lesson, Greg Damico discusses API's. API's are everywhere, but attention will be paid to the interface between a user and the data resource from a website. Topics covered in this lesson include: What is an API, what are the parts of an API, the requests library, what is JSON, the JSON format, responses, status codes, hitting the right endpoint, access tokens, storing access keys securely, creating a .secrets folder, adding a .secrets folder to the gitignore file, .get, .response, status_code, common status codes, .content

The repository for this lecture can be found here - [API's](https://github.com/flatiron-school/ds-apis-nbz32)
