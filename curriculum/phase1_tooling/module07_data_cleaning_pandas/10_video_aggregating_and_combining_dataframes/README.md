# 🎬 Video: Aggregating and Combining DataFrames

> Part of **Topic 5: Data Cleaning in Pandas** · source item type: WikiPage

---
In this lesson Greg Damico discusses combining dataframes and some of the aggregating methods and functions in the pandas library. Aggregating is introduced with groupby and many methods and functions used with groupby. The topics in this lesson include: .groupby, .get_group, .groups, .keys, multi-indexing, pivoting a table using .pivot_table, .merge, .join, the how parameter in the .join method, pd.concat, and a brief introduction to the pandas.set_option method for customizing pandas.

The repository for this lecture can be found here - [Aggregating and Combining DataFrames](https://github.com/flatiron-school/ds-aggregating_combining_dataframes-nbz32)
