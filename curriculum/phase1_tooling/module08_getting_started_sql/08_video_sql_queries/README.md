# 🎬 Video: SQL Queries

> Part of **Topic 6: Getting Started with SQL** · source item type: WikiPage

---
In this lesson, Greg Damico presents a common language for interacting with databases, structured query language (SQL). Topics covered in this lesson include: what are relational databases, an introduction to SQLite, connecting to a database, getting schema information, using pandas to read an SQL query, the basics of a query including select, where, order by, and limit as well as primary key, foreign key, cursor, connect, fetchall, distinct, as, cast, aliases, and some aggretating key words such as sum, max, and min and customizing results using limit and order by.

The repository for this lecture can be found here - [SQL Queries](https://github.com/flatiron-school/ds-sql_queries_nbz32)
