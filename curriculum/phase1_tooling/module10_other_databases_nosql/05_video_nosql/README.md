In this lesson Greg Damico introduces NoSQL along with a popular tool for these databases called MongoDB. In this lesson you will learn what NoSQL is, what MongoDB is, how to use MongoDB from the command line, inside a Jupyter notebook using PyMongo, and from the web using MongoDB Atlas. Greg introduces some useful key words and talks a little about the benefits of MongoDB.

The repository for this lecture can be found here - [NoSQL](https://github.com/flatiron-school/ds-nosql-bqs32)
