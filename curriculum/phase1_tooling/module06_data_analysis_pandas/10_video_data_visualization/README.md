# 🎬 Video: Data Visualization

> Part of **Topic 4: Data Analysis in Pandas** · source item type: WikiPage

---
An introduction to visualizations using the matplotlib library. In this lesson some of the topics covered include figure best practices, creating basic plots such as line plots, bar plots and histograms, customizing your plots using parameters such as x-ticks, labels, colors etc. Also covered are multiple plots on one figure and saving your figure as an image.

The repository for this lecture can be found here - [Data Visualization](https://github.com/flatiron-school/ds-data_visualization-async-bqs-32)
