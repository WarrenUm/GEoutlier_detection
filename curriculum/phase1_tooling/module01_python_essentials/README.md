# Module 01 — Python Essentials

Adapted from the source curriculum module **Python Essentials**,
re-grounded in OSRS market data. Work each lesson in order; open the
lesson `README.md`, then do your work in that lesson's `work.ipynb`.

See the root [README](../../../README.md) for where this module sits in the
overall roadmap.

- [`01_introduction_to_variables_variable_assignment/`](01_introduction_to_variables_variable_assignment/README.md) — Introduction to Variables: Variable Assignment
- [`02_introduction_to_variables_strings/`](02_introduction_to_variables_strings/README.md) — Introduction to Variables: Strings
- [`03_introduction_to_variables_numeric_types_and_booleans/`](03_introduction_to_variables_numeric_types_and_booleans/README.md) — Introduction to Variables: Numeric Types and Booleans
- [`04_control_flow_conditionals/`](04_control_flow_conditionals/README.md) — Control Flow: Conditionals
- [`05_working_with_lists/`](05_working_with_lists/README.md) — Working with Lists
- [`06_working_with_dictionaries/`](06_working_with_dictionaries/README.md) — Working with Dictionaries
- [`07_built_in_python_operators_functions_and_methods/`](07_built_in_python_operators_functions_and_methods/README.md) — Built-in Python Operators, Functions and Methods

## How to work a lesson

1. Read the lesson `README.md`.
2. Do the work in `work.ipynb` (load OSRS data via `ge_data` where it fits).
3. Run `pytest` in the lesson folder — it executes your notebook.
