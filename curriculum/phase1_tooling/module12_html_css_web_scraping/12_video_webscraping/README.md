# 🎬 Video: Webscraping

> Part of **Topic 10: HTML, CSS and Web Scraping** · source item type: WikiPage

---
In this lesson, Greg Damico discusses the fundamentals of webscraping. BeatuifulSoup is introduced, and used in conjunction with the requests library to scrape data from the web. Topics covered include: the components of a webpage, and introduction to html and som common html tags, inspecting a web page to determine the format of the contents, parsing a pages contents with BeautifulSoup, the concept of parents, children and siblings, finding all instantces of a tag at once using find_all, pulling in a table and combining the data into a dataframe.

The repository for this lecture can be found here - [Webscraping](https://github.com/flatiron-school/ds-webscraping-nbz32)
