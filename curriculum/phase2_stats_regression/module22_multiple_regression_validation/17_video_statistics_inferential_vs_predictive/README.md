# 🎬 Video: Statistics: Inferential vs. Predictive

> Part of **Topic 19: Multiple Regression and Model Validation** · source item type: WikiPage

---
In this lecture Greg Damico discusses the differences between inferential statistics and predictive statistics. Topics covered in this lecture include: inferential statistics, predictive statistics, expected value, bias, variance, error as a function of prediction, irreducible error, prediction error as a combination of bias and variance

The repository for this lecture can be found here - [Statistics: Inferential vs. Predictive](https://github.com/flatiron-school/ds-sql2-nbz32)
