re-grounded in OSRS market data. Work each lesson in order; open the
lesson `README.md`, then do your work in that lesson's `work.ipynb`.

overall roadmap.

## How to work a lesson

1. Read the lesson `README.md`.
2. Do the work in `work.ipynb` (load OSRS data via `ge_data` where it fits).
3. Run `pytest` in the lesson folder — it executes your notebook.
